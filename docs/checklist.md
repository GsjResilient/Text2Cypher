# PPT 功能核对

- T1 六阶段：Schema、Prompt、大模型客户端、校验、执行、结果格式化均已实现。
- 三档入口：简单、中等、复杂；单条查询与 TXT 批量任务。
- 输出：拓扑、数据表、Cypher、自然语言总结、过程日志及 Markdown 报告。
- T2：30 组真实查询示例，新增/编辑/删除/分类/搜索，DeepSeek 语义选择。
- 实体消歧：同名方法候选与补充说明，选择后继续查询。
- T3：RPC、MQ、反向影响、独立子查询与基于 ID 的依赖传递，部分失败状态。
- 评估：30 题（10/12/8），独立参考查询，结果集合比较与人工复核，等级统计。
- 本地配置：模型密钥与 Neo4j 凭据仅在 `.env`，不进入前端。
- Skill 化：Prompt 当前作为源码模块管理，独立 SKILL.md 封装不是本版必做项。
- 人工验收：AI 编写示例的课程合规复核、正式评分仍需团队确认。
- 浏览器视觉验收：本次环境没有可连接的浏览器；已进行模拟 DOM 的交互测试，不能替代真实浏览器视觉检查。

实际执行和评估结果见 `reports/evaluation.md` 与对应 JSON 原始证据。
